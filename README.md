# nutricore-frontend

Interfaz web para registro y filtrado de alimentos por macronutrientes.

## Stack
- React 18
- Vite
- Jest + React Testing Library
- Nginx (producción)

## Arrancar en local
```bash
cp .env.example .env
npm install
npm run dev
```
